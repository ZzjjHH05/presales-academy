## 📌 一句话结论

攒案例 ≠ 收藏链接，而是**用统一模板把案例拆成"一句话能讲"的结构**：行业 → 痛点 → 方案 → 价值。

## 🧠 知识要点

### 案例拆解四要素

1. **行业/客户画像**：什么行业、多大规模、什么角色（别只写公司名）；
2. **痛点（Why）**：客户之前遇到什么问题，量化最好（"每年停机 X 小时"）；
3. **方案（How）**：用到了什么产品/架构，关键动作是什么；
4. **价值（Value）**：效果与收益，尽量有数字（成本降 X%、效率升 X 倍、合规达标）。

### 模板（可直接复制使用）

> **一句话版**：为【行业/客户】解决【痛点】，用【方案】，实现了【价值】。

```
案例名称：
行业/规模/角色：
客户现状：
核心痛点（量化）：
方案概述（架构一句话）：
用到哪些产品/技术：
效果与价值（量化）：
我的思考（可复用点 / 局限）：
```

### 从哪找案例原料

- 厂商官网的"行业解决方案/客户案例"页；
- 云厂商的白皮书、最佳实践（AWS/阿里云/华为等）；
- 招标文件里的"类似项目业绩"描述；
- 自己实习/项目里参与过的任何客户场景。

### 面试用法

面试官问"讲一个你了解的项目/案例"时，用这个结构答 2-3 分钟：
先一句结论 → 痛点 → 方案 → 价值 → **最后加一句你的思考**（差异化）。

## 💼 面试怎么问

- "讲一个你熟悉的方案/案例" → 套四要素模板；
- "你凭什么说你懂这个行业" → 用拆过的 2-3 个案例证明结构化的积累。

## ✅ 自检清单

- [ ] 手上有至少 3 个用模板拆好的案例
- [ ] 每个案例都能 30 秒讲出"痛点-方案-价值"
