## 📌 一句话结论

云话题在售前交流里出现频率极高，核心就三件事：**分层（IaaS/PaaS/SaaS）、模式（公有/私有/混合）、迁移（怎么过去）**。

## 🧠 知识要点

### 服务分层（最常考）

| 分层 | 你管什么 | 供应商管什么 | 例子 |
|---|---|---|---|
| IaaS | 应用、数据、OS | 虚拟化、服务器、网络、存储 | 云服务器、云硬盘 |
| PaaS | 应用、数据 | OS 到运行平台 | 云数据库、容器服务、函数计算 |
| SaaS | 只用不建 | 全部 | 在线办公、CRM |

> 讲法："云上分层越高，客户自管越少、越省运维，但越受平台约束——方案里要讲清楚取舍。"

### 部署模式

- **公有云**：弹性、成本低，适合互联网与弹性业务；
- **私有云**：自主可控、安全合规要求高（政企、金融、涉密）；
- **混合云**：核心敏感数据留在本地 + 弹性/创新上公有云，**政企场景最常见**。

### 上云迁移的常用词

- 迁移五阶段：评估 → 规划 → 迁移 → 验证 → 优化；
- 迁移模式（6R）：Rehost（搬）、Replatform（换平台）、Refactor（重构）、Relocate、Retain、Retire；
- 常见顾虑：数据安全、迁移停机窗口、成本翻倍（要讲 ROI 与 FinOps）。

### 虚拟化与容器一句话区分

- 虚拟化：一台物理机跑多个"虚拟机"，隔离靠 Hypervisor，资源开销较大；
- 容器：共享内核、隔离靠 Namespace/cgroup，启动快、资源省，配合 K8s 编排。

## 💼 面试怎么问

- "混合云和私有云什么区别？" → 私有云是自建/独享的云，混合云是本地+公有的组合；
- "客户说不想上云，你怎么回应？" → 先认同顾虑（安全/成本/合规），再讲"不一定全上云"，给出混合与分步迁移路径；
- "什么是容器？" → 共享内核的轻量运行单元，配合编排工具管理集群。
