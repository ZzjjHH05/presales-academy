## 📌 一句话结论

售前表达的核心不是口才，而是**结构化 + 分听众 + 会控场**：先讲结论，再按对方关心的角度展开。

## 🧠 知识要点

### 表达基本功：先结论后细节

- 结论先行：30 秒讲完"我要说什么、为什么、要你做什么"；
- 金字塔结构：结论 → 3 个支撑点 → 每个点有例证；
- 少用术语堆砌：出现术语就补一句人话翻译。

### 给不同听众讲不同重点

| 听众 | 关心什么 | 怎么讲 |
|---|---|---|
| 业务方 | 能不能解决问题 | 讲场景与效果，配案例 |
| 技术方 | 可不可行、兼容性 | 讲架构、接口、迁移路径 |
| 决策者 | 值不值、有没有风险 | 讲 ROI、风险控制、节奏 |
| 评委（招投标） | 是否响应评分点 | 逐条应答、给证据 |

### 控场与答疑

- 讲标开场先定框架："我用 20 分钟讲三块——理解、方案、差异化"；
- 答疑三原则：**会就答、不会就记、价格问题交商务**；
- 被挑战时不辩解，先认同再解释："您这个担心很有道理，我们的做法是……"；
- 演练降级：现场演示备好离线/备用方案。

### "讲成人话"的三个替换

1. "实现海量数据的实时分析" → "以前报表要等一天，现在当天点开就看得到"；
2. "通过微服务架构解耦" → "把一个大系统拆成多个小系统，一个出问题不影响别的"；
3. "采用零信任安全模型" → "不因为你在内网就无条件信任，每个人每次访问都要验证身份"。

## 💼 面试怎么问

- "介绍下你刚才那个方案"（压力测试）→ 用结论先行 + 三层结构；
- "客户嫌你技术性太强听不懂怎么办" → 讲分层与"讲成人话"三替换；
- 常见现场题：给 3 分钟向非技术背景的人解释一个技术概念。

## ✅ 自检清单

- [ ] 任何话题都能"先结论后三点"
- [ ] 会给同一方案准备"对业务 / 对技术 / 对老板"三种讲法
- [ ] 能熟练把 3 个技术术语翻译成人话
