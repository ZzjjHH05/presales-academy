## 📌 一句话结论

理解一个行业，不用先学技术，而是先回答四个问题：**客户在做什么生意？最大的痛点是什么？谁来拍板？钱从哪里出？**

## 🧠 知识要点

### 四问框架

1. **业务**：这个行业/这家公司靠什么赚钱？核心业务链条是什么？
2. **痛点**：业务链条上哪一环最痛（成本、效率、合规、安全、体验）？
3. **客户**：我的甲方是谁？他们的客户又是谁（要理解"客户再往下服务谁"）？
4. **决策链**：谁懂业务、谁懂技术、谁管预算、谁最后拍板？

### 一个行业速查表（模板）

| 维度 | 要弄清楚的问题 |
|---|---|
| 行业规模与周期 | 是增长还是收缩？政策是否鼓励 |
| 业务模式 | 制造/服务/平台？B2B 还是 B2C |
| 监管与合规 | 有没有强监管？数据、安全、资质要求 |
| 客户画像 | 大客户还是长尾？项目制还是订阅制 |
| 关键指标 | 行业最在意什么 KPI（如医院关注满意度与合规） |
| 竞品与格局 | 主要玩家、各自的差异化 |

### 决策链拆解（ToB 常见角色）

- **业务方（需求方）**：提需求，关注"能不能解决业务问题"；
- **技术方（把关者）**：审方案可行性、兼容性，会说"不"；
- **采购/商务（执行者）**：走流程、比价格；
- **决策者（拍板人）**：看价值、看风险、看关系。

> 售前的一个基本功：**给不同的角色讲不同的重点**——对业务讲价值，对技术讲架构，对老板讲 ROI 与风险。

## 💼 面试怎么问

- "你对我们公司的行业了解多少？" → 用四问框架现场拆解，展示方法论而非死记数据；
- "如果让你快速了解一个新行业，你怎么做？" → 答"业务-痛点-客户-决策链"四问 + 一手资料（官网、年报、招股书、研报）。
