## 📌 一句话结论

招投标的核心是**"不废标 + 得分点全中"**：先保证资格与技术应答零差错，再靠讲标把分数拉开。

## 🧠 知识要点

### 读懂一份招标文件

1. **招标公告/邀请函**：资格要求、时间节点、保证金；
2. **技术需求/技术规格**：评分办法、技术条款（★ 号项多为必须满足）；
3. **商务部分**：价格分、资质、业绩；
4. **评标办法**：综合评分 / 最低价 / 性价比——决定策略重心。

> 黄金动作：把招标文件里的每一项技术条款**逐条编号做成应答对照表**，标出"响应/偏离/证明材料"。

### 标书常见硬伤（务必避免）

- 缺页、错页、装订错误、签字盖章遗漏；
- 资质/业绩证明材料不齐；
- 技术条款应答含糊、照抄原文未响应；
- 商务与技术报价不一致；
- 超过递交截止时间。

### 讲标（述标）怎么讲

- 讲清三件事：**理解（我懂你的问题）→ 方案（我这样解决）→ 差异化（为什么选我）**；
- 时间纪律：按评分点分配时间，别在某个细节恋战；
- 答疑原则：**会就答，不会就记**，绝不编；敏感价格问题交给商务。
- 演示小心机：现场 Demo 提前备好环境与降级方案（断网、软件崩溃都有 Plan B）。

### 一个小记忆点

- **资格标**：满足门槛；**技术标**：拿分主体；**商务标**：价格与报价策略。

## 💼 面试怎么问

- "你做过招投标吗 / 你怎么学招投标？" → 即使没做过，也要展示"读过公开招标文件、会做技术应答对照表"的学习动作；
- "讲标时被评委问倒怎么办？" → 承认不确定 + 承诺书面答复，展示职业素养。

## ✅ 自检清单

- [ ] 会做"招标条款 → 应答 → 证明材料"的对照表
- [ ] 能说出三类标（资格/技术/商务）各自重心
- [ ] 能给讲标设计"理解-方案-差异化"三分钟结构
