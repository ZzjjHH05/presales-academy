## 📌 一句话结论

竞品分析的目的不是"比参数"，而是**找到客户在乎而我们占优的维度，把差异翻译成客户语言**。

## 🧠 知识要点

### 竞品分析五维框架

| 维度 | 看什么 |
|---|---|
| 产品 | 功能、架构、技术路线、成熟度 |
| 价格 | 报价结构、折扣空间、总拥有成本 |
| 渠道与服务 | 交付能力、售后、生态 |
| 口碑 | 客户案例、行业评价、负面信息 |
| 打法 | 对方在客户处怎么讲、押什么点 |

### 差异化维度（不只比功能）

1. **技术/架构**：性能、安全性、开放性、信创兼容；
2. **行业 Know-how**：懂这个行业的业务和流程，比功能强；
3. **服务与交付**：本地团队、响应速度、实施经验；
4. **生态与合规**：认证、资质、客户案例背书。

### 把差异做成方案亮点（"防御性方案"思路）

- 先想"客户可能被竞品打动什么"，提前在方案里**堵住漏洞**（价格、风险、迁移成本）；
- 每个差异点配**证据**：案例、数据、演示、资质；
- 讲差异时**不贬低竞品**，讲"我们更适合这个场景"。

### 避坑

- 只列功能对比表，没有"so what"；
- 贬低竞品（显得不专业，也容易被打脸）；
- 差异点不是客户关心的点（自嗨）。

## 💼 面试怎么问

- "如果竞品比我们便宜 30%，你怎么谈？" → 价值量化 + 分层方案 + 风险/总拥有成本；
- "你怎么了解竞品？" → 官网/白皮书/客户口碑/行业报告，展示方法。

## ✅ 自检清单

- [ ] 会搭"产品/价格/服务/口碑/打法"五维框架
- [ ] 每个备选差异点都能配一个证据
- [ ] 有一句"不贬低竞品但突出自己"的话术
