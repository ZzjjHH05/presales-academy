question: HTTP 和 HTTPS 有什么区别？为什么政企项目几乎都要求 HTTPS？
hint: 从加密、端口、证书三点讲，落到客户侧的安全意义

**参考答案要点**

- **HTTP**：明文传输，默认端口 80，可被中间人窃听/篡改。
- **HTTPS**：HTTP + TLS，默认端口 443，加密 + 完整性 + 身份可信。
- **证书**：由可信 CA 签发，证明"这把公钥确实是你的"，防冒充；政企常还要国密证书。
- **客户侧意义**：政企/金融数据合规与审计要求传输加密，HTTPS 是底线，证书要在方案里列清谁来出。

**售前向要点**：讲完补一句对客户的意义——"所以方案里我们默认全站 HTTPS，证书用 CA 还是国密按你们合规要求来"，显得不是背概念而是帮客户合规。

**避坑**：只说"HTTPS 更安全"不讲为什么；说不出端口和证书；把 HTTPS 当成"绝对安全"。
